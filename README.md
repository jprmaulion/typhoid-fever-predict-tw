# Forecasting Typhoid Fever Cases in Taiwan using Temporal Features and PBT-Tuned XGBoost

## Project Overview

This project involves the development of a predictive model for forecasting typhoid fever cases in Taiwan, leveraging temporal features and an XGBoost model with hyperparameters optimized via Population Based Training (PBT). The goal is to understand disease dynamics, enabling better preparedness and response strategies for public health officials.

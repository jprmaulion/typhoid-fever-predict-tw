# Forecasting Typhoid Fever Cases in Taiwan using Temporal Features and PBT-Tuned XGBoost

## Project Overview

I developed a predictive model to forecast typhoid fever cases in Taiwan, leveraging temporal features and an XGBoost model with hyperparameters optimized via Population Based Training (PBT). The goal is to understand disease dynamics, enabling better preparedness and response strategies for public health officials.
